생성일: 2026-08-20 UTC. 이 문서는 제품 코드·설정·의존성·공개 사이트·저장 기록을 바꾸지 않은 별도 분석 결과다.

## 1. 대상 서비스

KABU LENS는 일본 상장사의 공시와 재무 근거를 구조화하고, 특히 경영진의 정량 약속과 실제 실적을 비교하는 32개 판정을 만들려는 공개 정적 PWA다. 공개판은 12개 조사 화면, 관심·보유·약속·공시·내 CSV, 로컬 저장·복구, 설치형 웹앱 안내를 제공한다. 실제 EDINET·시세 수집과 상용 운영은 코드와 문서에서 차단 또는 미확인 상태다.

## 5. 합성된 이상 기준과 대조

상세 기준은 [ideal-standard.json](ideal-standard.json)에 15개로 기록했다. 가장 중요한 결론은 다음과 같다.

1. **차별성은 존재하나 실제 데이터 검증이 없다.** E03과 원문 근거 계약은 코드로 확인되지만, 실제 공시 30건 이상을 통한 정확도·재현성 시험이 없다.
2. **탐색 기능은 아직 기본 수준이다.** 기업 찾기는 있으나 선두 사례의 저장 필터, 정렬, 대규모 결과, CSV 결과 내보내기와 거리가 있다.
3. **PWA의 코드 기반은 있으나 설치형 시험이 부족하다.** 서비스 워커 앱 껍질·업데이트 안내는 검사되었지만, 최근 공개판의 Android 독립 실행·업데이트와 iPhone 시험은 미확인이다.
4. **상용 신뢰 표면은 미완성이다.** 공개 이용약관, 개인정보 처리방침, 사업자 정보, 문의, 데이터 권리의 계약 증거를 찾지 못했다.
5. **운영 관찰이 비어 있다.** 실제 수집·판정·오류·지연을 보는 경보와 복구 훈련은 미확인이다.

## 7. 강점 3개

1. **명확한 분석 가설:** 일본어 공시의 정량 약속을 실제 결과와 대조한다는 초점이 일반 시세·뉴스 나열과 다르다.
2. **보수적인 데이터 권리 경계:** 무계약 시세 수집·TDnet 원문 재배포·투자 조언을 금지하고, CSV 비저장 검증과 JPX 링크 방식을 둔다.
3. **사용자 자료 보호 기반:** 저장자료 이전·손상 원문 보존·복구 검사가 자동으로 확인됐다.

## 14. Android 실기기 시험 상태

## 15. 1,000명 가상 페르소나

기존 기록의 합성 1,000명×12 시나리오는 제품 규칙과 흐름을 반복 확인한 증거다. 이는 실제 사람이 느낀 유용성·신뢰·지불 의향 증거가 아니며, 실제 사용자 시험을 대체하지 않는다. 이 분석은 해당 결과를 사용성 점수 상향 근거로 사용하지 않았다.

## 16. 결론

**부분 완료.** KABU LENS는 차별적 분석 가설, 공개 PWA, 자동 웹 검사, 보수적 데이터 권리 경계를 갖췄다. 다만 핵심 기능의 실제 공시 검증, 데이터 권리, 상용 정책·운영 표면, 실제 설치형 웹앱 시험이 남아 있어 상용 출시 준비 완료로 판정할 수 없다.
